# 2단계 보드 판정

초기 배치가 반환한 `position`을 입력으로 사용한다. 보드 행동은 새 상태를 반환하므로 행동 전후를 비교하거나 같은 카드로 판정을 재현할 수 있다. 기준은 기본 규칙서 8~13·18쪽, 오토마 규칙서 2·4~8쪽이다.

## 오토마 건설 예시

오토마 규칙서 7쪽에서 파란 오토마의 항해력은 1이다. 규칙서 그림을 작은 보드 좌표에 대응시키면 다음 과정을 재현할 수 있다.

| 판정 | 남은 후보 또는 결과 |
|---|---|
| 두 건물군의 거리를 줄이는 칸 | 그림 안의 체크 표시 네 곳은 E5, E7, F2, F3이다. 전체 보드에서 그림에 보이는 기물만 놓으면 그림 바깥의 E8도 이 조건을 통과한다. |
| 지형 우선순위 B | 호수 E7, F2가 남는다. |
| 사람 건물과의 최단 거리 | E7이 E6의 사람 건물에 인접해 선택된다. |
| 배치 직전 표식 거리 | E7에서 가장 가까운 표시 건물까지 사이 칸 1개, 미표시 건물까지 0개이므로 새 작업장은 미표시다. 동거리일 때도 미표시다. |

일반 보드 행동은 아래처럼 호출한다. `supportCardId`에는 지원 카드 번호를 전달한다. `trace`는 후보 목록을 판정 순서대로 담고, `powerOffered`는 인접한 사람 건물의 마력 합계를 반환한다.

```js
import { resolveAutomaBoardAction } from '../src/game/automa-board.mjs'

const result = resolveAutomaBoardAction(position, 'transform-and-build', supportCardId, round)
const nextPosition = result.position
```

작업장 재고나 도달 가능한 빈 땅이 없으면 건물을 개량한다. 개량할 때는 사람 건물 옆의 작업장, 사람에게 제공하는 마력이 적은 칸, 카드 방향과 순번을 차례로 적용한다. 개량할 건물도 없으면 상태를 유지한다. 종족 카드 전용 행동은 후속 단계에서 일반 행동과 연결한다.

## 플레이어 행동과 점수

- `adjacentLand`는 변을 공유하거나 완성된 다리로 이어진 육지를 반환한다. `landInReach`는 여기에 항해력만큼의 연속된 강을 건너 닿는 육지를 더한다. 오토마의 최단 거리에서는 강과 오토마 건물을 통과할 수 있고 사람 건물을 돌아간다.
- `terraformAndBuild`는 일반 건설 행동 한 칸의 도달 여부, 최단 방향 지형 변환, 작업장 재고를 검사하고 사용한 삽 수와 새 보드를 반환한다. `upgradePlayerBuilding`은 일반 개량 경로와 기물 재고를 검사한다. 자원 지불과 여러 칸에 무료 삽을 배분하는 순서는 턴 엔진에서 처리한다.
- `foundCities`는 플레이어의 인접 건물군에서 새 도시를 찾아 기록한다. 같은 도시는 다시 보상 후보가 되지 않는다. 대학·기념물의 최소 건물 수와 별관의 추가 마력·건물 수도 적용한다.
- `areaScoring`에는 플레이어의 영구 항해력을 전달한다. 오토마는 난이도 카드의 최고 항해력을 사용한다. 양측 최대 연결 건물 수와 각자의 점수를 반환한다. 두더지족의 터널과 궁전의 비행도 최종 연결에 사용할 수 있다.
